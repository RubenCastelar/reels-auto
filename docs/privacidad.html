Política de privacidad de Reels Auto

Última actualización: 7 de noviembre de 2026

Reels Auto es una herramienta personal de Rubén Castelar (@rubi_castelar en Instagram) que responde automáticamente por mensaje privado a las personas que comentan una palabra clave en sus Reels. Esta política explica qué datos se tratan y cómo.

1. Qué datos se tratan

  • Del comentario: identificador del comentario, texto del comentario, identificador de Instagram (ID) y nombre de usuario de quien comenta, e identificador de la publicación.
  • Del mensaje: el identificador de quien pulsa el botón del mensaje privado y, si procede, la respuesta «SI».
  • Del perfil: únicamente si esa persona sigue o no la cuenta @rubi_castelar, para decidir si se le envía el contenido.

2. Para qué se usan

Solo para enviar el mensaje prometido en el Reel (por ejemplo, un enlace o un recurso) y para comprobar, cuando se pide, que la persona sigue la cuenta. No se usan para publicidad, perfiles, ventas a terceros ni ningún otro fin.

3. Cuánto tiempo se conservan

  • El identificador de un comentario ya atendido se guarda 7 días, solo para no responder dos veces.
  • Una marca temporal de «esperando respuesta» se guarda 24 horas.
  • No se almacena el texto de los comentarios ni los mensajes, ni se crea una base de datos de personas.

4. Con quién se comparten

No se venden ni se ceden datos a terceros. El tratamiento se realiza mediante la API de Instagram (Meta Platforms) y se aloja en Cloudflare, que actúa como proveedor técnico.

5. Tus derechos y cómo borrar tus datos

Puedes pedir en cualquier momento que se eliminen los datos asociados a tu cuenta. Las instrucciones están en la página de eliminación de datos.
